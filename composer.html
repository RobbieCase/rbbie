how to publish / edit / remove

  1. Publish: copy the article file → in GitHub, Add file → Create new file, name it exactly what's shown above, paste, commit. Then copy the entry and paste it at the top of the ARTICLES list in abyss.html, commit. Done — it's live.
  2. Edit: re-write it here and re-copy the file over the old one in GitHub (open the file → pencil icon → paste → commit). If you changed the title or summary, update its line in abyss.html too.
  3. Remove: in GitHub, delete the article's .html file, and delete its line from the ARTICLES list in abyss.html.
